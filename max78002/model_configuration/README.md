# max78002/model_configuration/

Start with `ecg-max78002.yaml`.

1. `ecg-max78002.yaml`: the layer description for `ai8xize.py`, one entry per accelerator layer (operation, kernel size, padding, pooling, activation, processors, output offset). Generated by `src/ecg/deployment/network_yaml.py` from `configs/model.yaml`.
2. `ai87net-ecg.py`: the same network as `src/ecg/models/ai8x_cnn.py`, in the file format of `ai8x-training/models/`.
3. `ecg_mitbih.py`: a dataset loader for `ai8x-training/datasets/` that serves `data/processed/`.

How they connect: the YAML must match the trained layers exactly; `ai8xize.py` checks it against the checkpoint. The two Python files let the group reproduce training inside the official framework (`python train.py --model ai87ecgnet --dataset ecg_mitbih --device MAX78002 ...`); the project trains with its own loop and the same ai8x layers instead.
